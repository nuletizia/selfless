Selfless

Citation filters for Google Scholar profiles. Citations are checked against OpenAlex; nothing else leaves your browser.

Without a key, OpenAlex gives every network a small shared daily budget. A free personal key is enough for any single profile. Get one at openalex.org/settings/api and paste it here. It is stored only in this browser and sent only to OpenAlex.

Selfless finds the OpenAlex author from the papers on the Scholar page. If it picks the wrong one, or the author is split across several OpenAlex IDs, set them here. One profile per line: Scholar user ID, an equals sign, OpenAlex author IDs separated by commas.

Cache

Results are kept for 7 days per profile. Clear them to force a fresh computation everywhere.

Selfless is an independent open-source project, not affiliated with Google. Source code.
